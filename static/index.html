How owo thinks

Three ideas, straight from the README.

  1. 1
    Heuristic first, LLM only when stuck

    Common patterns parse offline. Inputs outside the rule set return unknown + needs_llm_provider — the provider is called only then.

  2. 2
    Never guess — flag it

    Send money to Tunde → amount: null + missing_amount. Per-field confidence says which field to distrust; min_confidence is your go/no-go gate.

  3. 3
    Built for how Naija speaks

    Code-switching, 5k, half a milli, dubu goma — and bank splitting on “, GTBank”.
